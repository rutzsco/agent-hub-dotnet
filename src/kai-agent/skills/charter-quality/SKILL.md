# Charter Quality Standards

Use this skill to evaluate the quality of a Kaizen event charter. Apply the
scoring rubric below to each section, then calculate an overall quality score.

## Scoring Rubric (0-100 scale)

### Problem Statement (25 points max)
- **25 pts**: Data-driven, specific, measurable, no assumed solutions. Includes baseline metric, gap, and impact.
- **20 pts**: Specific and measurable but missing one element (e.g., no impact quantification).
- **15 pts**: Describes the problem but is vague on metrics or scope.
- **10 pts**: Exists but is solution-oriented or lacks specificity.
- **0 pts**: Missing or generic ("We need to improve things").

### Scope & Schedule (15 points max)
- **15 pts**: Clear start/end points, defined boundaries, realistic timeline, process identified.
- **10 pts**: Boundaries defined but missing process mapping or timeline concerns.
- **5 pts**: Vague scope ("the shipping area") with no specific boundaries.
- **0 pts**: Missing.

### Metrics & KPIs (20 points max)
- **20 pts**: SMART targets with baseline, target, gap, and trend for primary KPI. Supporting metrics defined.
- **15 pts**: Primary KPI defined with baseline and target but missing trend or supporting metrics.
- **10 pts**: KPI exists but is not measurable or has no baseline.
- **0 pts**: No metrics defined.

### Team Composition (15 points max)
- **15 pts**: Cross-functional team, facilitator assigned, sponsor identified, roles clear.
- **10 pts**: Team identified but missing cross-functional representation or unclear roles.
- **5 pts**: Minimal team information.
- **0 pts**: No team defined.

### Obstacles & Resources (10 points max)
- **10 pts**: Key obstacles identified with mitigation strategies. Required resources listed.
- **5 pts**: Obstacles listed but no mitigation plans.
- **0 pts**: Not addressed.

### Sustainability (15 points max)
- **15 pts**: Follow-up plan with ownership, sustainability metrics, and review schedule.
- **10 pts**: Follow-up plan exists but missing metrics or ownership.
- **5 pts**: Generic follow-up mention.
- **0 pts**: No sustainability plan.

## Quality Tiers
- **90-100**: Excellent — ready for execution
- **75-89**: Good — minor gaps, can proceed with notes
- **50-74**: Needs improvement — significant gaps should be addressed before execution
- **Below 50**: Incomplete — requires substantial revision

## Common Quality Issues
1. **Vague problem statements**: "We need to reduce waste" vs. "Scrap rate on Line 4 is 8.3% against a target of 3%, costing $45K/month"
2. **Solution-embedded problems**: "We need to install new software" (that's a solution, not a problem)
3. **Missing baselines**: Setting targets without knowing the current state
4. **Scope creep indicators**: Trying to address too many processes in one event
5. **Absent sustainability**: No plan for maintaining gains after the event
