# KPI & Metrics Guidance

Help users define effective KPIs that drive meaningful improvement.

## SMART Metrics Framework

Every KPI should be:
- **S**pecific — Clearly defined, no ambiguity about what is measured
- **M**easurable — Quantifiable with available data
- **A**chievable — Realistic given constraints and resources
- **R**elevant — Aligned with the problem statement and organizational goals
- **T**ime-bound — Has a defined timeline for achievement

## Metric Types

### Primary KPI
The single most important measure of success for the event:
- Directly tied to the problem statement
- Has a clear baseline (current state) and target (future state)
- Can be measured before, during, and after the event

### Supporting Metrics
Additional measures that provide context:
- **Leading indicators**: Predict future performance (e.g., training completion rate)
- **Lagging indicators**: Confirm results (e.g., monthly defect rate)
- **Process metrics**: Measure intermediate steps (e.g., cycle time per station)
- **Balancing metrics**: Ensure improvement in one area doesn't degrade another

## Common Metric Categories

| Category | Example Metrics |
|----------|----------------|
| Quality | Defect rate, first-pass yield, rework %, scrap rate |
| Delivery | On-time delivery %, lead time, cycle time, throughput |
| Cost | Cost per unit, overtime hours, waste $, inventory carrying cost |
| Safety | Incident rate, near-miss reports, days since last incident |
| People | Training hours, cross-training %, engagement score |

## Setting Effective Targets

### Do
- Base targets on data (historical performance, benchmarks, standards)
- Include the unit of measure (%, days, $, count)
- State both baseline and target values
- Consider what's achievable in the event timeframe

### Don't
- Set arbitrary targets ("reduce by 50%" without justification)
- Set targets that require factors outside the team's control
- Forget to define how the metric will be measured
- Ignore trends — a worsening trend may need a more aggressive target

## Gap Analysis Template
```
Metric: [Name]
Unit: [%, days, $, count, etc.]
Baseline: [Current value with date range]
Target: [Desired value]
Gap: [Baseline - Target]
Trend: [Improving / Stable / Worsening]
Data Source: [Where this data comes from]
Measurement Frequency: [Daily / Weekly / Monthly]
```
